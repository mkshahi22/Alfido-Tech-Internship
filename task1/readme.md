# Hello World Project

## Overview
This is **Task 1** of the **Alfido Tech Internship Program** as a **Java Developer Intern**.  
The project demonstrates a simple interactive **Hello World application** in multiple languages using Java. It allows users to print "Hello World" in English, Hindi, Spanish, or French multiple times.

---

## **Technologies Used**
- Java (OOP Concepts)
- Scanner for user input
- Switch-case and loops for functionality

---

## **Features**
- Interactive menu-driven program
- Print "Hello World" in multiple languages:
  - English
  - Hindi
  - Spanish
  - French
- Print multiple times as per user input
- Graceful exit option
